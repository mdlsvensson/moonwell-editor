# Object Editor, milestone 4 (map archives: `.w3x`, `.w3m`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open, edit and save a map stored as a `.w3x`/`.w3m` archive as safely as a map folder: every file the user
did not change comes back unchanged, and nothing replaces the map until the new archive has been checked.

**Architecture:** A map store interface in `ObjectEditor.Files` with two kinds: the existing folder and a new archive
store on War3Net's MPQ code (`MpqArchive`, `MpqArchiveBuilder`). The model and the app talk to the interface. The
archive store writes a whole new archive to a temporary file, re-opens it and compares every file, backs up the old
archive, then replaces it. The milestone starts with a throwaway spike that decides whether War3Net's MPQ code is good
enough.

**Tech Stack:** as milestones 1-3; `War3Net.IO.Mpq` (already a dependency of `Moonwell.War3Net.Build.Core`).

**Spec:** `docs/superpowers/specs/2026-10-26-object-editor-design.md`, sections "Map archives" and "Milestone 4:
archives in detail" (the agent's calls).

2. A map World Editor holds open (the file locked) refuses the save with a message naming World Editor, and nothing

5. Files the archive's list does not name (unknown files, kept only by their hash) survive a save. Test: Task 3
   `Unnamed_files_survive` (from the spike's findings: a test archive built with one unnamed file).

### Task 2: The map store and reading archives

**Files:** Create `src/ObjectEditor.Files/IMapStore.cs`, `MapArchive.cs`; modify `MapFolder.cs`;
create `tests/ObjectEditor.Files.Tests/MapArchiveTests.cs`, `tests/fixtures/moonwell-sample/` (copy `Sample.w3x` with
a `SOURCE.md`).

**Interfaces:**
- Produces:
  ```csharp
  public interface IMapStore
  {
      string Path { get; }                         // the folder or the archive file
      bool IsArchive { get; }
      byte[]? Read(string name);                    // null when the map has no such file
      void Write(IReadOnlyList<(string Name, byte[]? Bytes)> files);   // null deletes (archives: refuses a delete)
      DateTime Stamp();                             // folder: newest write time of the object files and .wts; archive: write time, size folded in
  }
  public static class MapStore { public static IMapStore Open(string path); }   // a directory → MapFolder, a file → MapArchive; else throws FileNotFoundException
  public sealed class MapArchive : IMapStore { public static MapArchive Open(string path); }   // throws MapArchiveException (message names the file and War3Net's reason) when War3Net cannot open it
  ```
  `MapArchive.Open` reads the archive once into memory (the bytes before the MPQ header, the list of files, the
  object files and `war3map.wts`) and closes the file, so World Editor is never blocked by the app.

### Task 3: Saving archives, checked

**Files:** Modify `MapArchive.cs`; add to `MapArchiveTests.cs`.

**Interfaces:**
- `MapArchive.Write(files)`: builds a new archive from the original with War3Net's `MpqArchiveBuilder`: each given
  file replaced (same `MpqFileFlags` as the original entry; a new file with War3Net's default), the bytes before the
  MPQ header written first; written to `<archive>.saving` in the same folder; re-opened and checked (each written file
  its new bytes, every other file of the original its old bytes, by name and, for unnamed files, by hash; the same
  number of files); then `File.Replace(saving, archive, null)`. On any failure the temporary file is deleted and a
  `MapArchiveException` says why; the archive is untouched. A locked archive gives the message "The map is open in
  another program (World Editor?): close it there and save again." A delete (`Bytes` null) throws (an object file is
  never removed from an archive).
- [ ] **Step 1:** Tests (on copies): `Save_changes_only_the_written_files` (replace `war3map.w3u` in `Sample.w3x`; every
  other file equal, by bytes); `Pre_archive_header_is_kept` (an archive with an `HM3W` header in front: the first 512
  bytes equal after a save); `Unnamed_files_survive` (per the spike); `Failed_check_leaves_the_map` (a test hook makes
  the check see a wrong file: the archive's bytes and write time unchanged, no `.saving` left); `Locked_archive_refuses_the_save`
  (the file opened with `FileShare.None` during the save); `Delete_is_refused`.
- [ ] **Step 2:** FAIL. **Step 3:** Implement. **Step 4:** PASS.
- [ ] **Step 5:** Commit `Files: saving archives, checked before they replace the map`.
